The 'Data_scraper.py' and the neural network training and testing files were all used to make the final live fall detection file, contributing to things such as manipulating video data to make the dataset and training and testing the machine learning model. These files are obsolete with the completion of the final 'Fall_detector' file and are only present to show the process of how the machine learning model was organized, trained, and tested, along with allowing changes and customization should you want to use this project as a backbone for your own.

The 'Fall_detector.py' file is completely independent of these files and can run without them, only needing the 'fall_model.pth' file which stores the LSTM parameters, and the 'common_functions.py' file which stores the functions the file uses to detect falls. If you simply want to see the finished program giving detecting if a fall has occurred in frame, simply open the 'common_functions.py' file, scroll to the bottom of the file to the 'send_fall_email' function and enter the email you want the alert sent from, sent to, and the app password for your sender email. Then open the 'Fall_detector.py' file and run the program.
